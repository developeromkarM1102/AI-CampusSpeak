# AI-CampusSpeak 🚀

AI-CampusSpeak is an AI-powered campus grievance and communication platform designed to bridge the gap between students and college administration by enabling transparent, efficient, and intelligent complaint management.

---

## 📌 Problem Statement

In many educational institutions, campus complaints and suggestions are handled through manual processes such as physical registers, emails, or informal communication. These systems suffer from several limitations:

- ❌ Lack of transparency in complaint status  
- ❌ Delayed responses from administration  
- ❌ No centralized system for tracking issues  
- ❌ Poor communication between students and authorities  
- ❌ No data-driven insights for recurring problems  

As a result, students feel unheard, and administrators struggle to manage and prioritize issues effectively.

---

## 💡 Solution: AI-CampusSpeak

AI-CampusSpeak solves these challenges by providing a **centralized, AI-powered digital platform** where:

- Students can raise and track complaints easily  
- Administrators can manage, update, and resolve issues efficiently  
- AI assists by summarizing complaints and suggesting possible actions  

---

## ✨ Key Features

### 👨‍🎓 Student Module
- Secure user authentication (JWT)
- Submit campus complaints and suggestions
- Track complaint status in real time
- Receive AI-generated suggestions and insights

### 🧑‍💼 Admin Module
- Secure admin login
- View all complaints in one dashboard
- Update complaint status (Pending / In Progress / Resolved)
- AI-powered complaint summaries for faster decision-making

---

## 🏗 System Architecture

AI-CampusSpeak follows a **modern MERN-based architecture** with AI integration.

🛠 Tech Stack
🌐 Frontend

React.js – Component-based UI development

Tailwind CSS – Utility-first styling for responsive design

JavaScript (ES6+) – Modern frontend logic

Axios / Fetch API – API communication

⚙ Backend

Node.js – JavaScript runtime environment

Express.js – RESTful API development

JWT (JSON Web Tokens) – Secure authentication & authorization

bcrypt.js – Password hashing & security

dotenv – Environment variable management

🗄 Database

MongoDB Atlas – Cloud-hosted NoSQL database

Mongoose – ODM for schema modeling and data validation

🤖 AI Integration

 OpenAI API – AI-powered complaint summarization and suggestions

🔧 Tools & Utilities

Git & GitHub – Version control & collaboration

Postman – API testing

VS Code – Development environment

🔐 Security & Best Practices

Environment Variables (.env) – Secure credential handling

CORS – Controlled cross-origin access

HTTPS – Secure data transmission
